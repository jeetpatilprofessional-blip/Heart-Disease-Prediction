# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview

A Machine Learning web application built using Streamlit that predicts the likelihood of heart disease based on patient health parameters. The model is trained on the Heart Disease dataset and provides real-time predictions through an interactive interface.

## 🚀 Features

- Predicts the likelihood of heart disease
- Interactive Streamlit web application
- Data preprocessing and feature engineering
- Trained Machine Learning classification model
- Easy-to-use user interface

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## 📂 Project Structure

```text
Heart-Disease-ML/
```

## 📊 Dataset

The project uses the Heart Disease Dataset, which contains patient health attributes such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Number of Major Vessels
- Thalassemia
- Target (Heart Disease)

## ⚙️ Installation

```bash
git clone https://github.com/jeetpatil/Heart-Disease-ML.git

cd Heart-Disease-ML

pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run app.py
```

Open the local URL shown in the terminal (usually http://localhost:8501).

## 📈 Model

- Problem Type: Binary Classification
- Framework: Scikit-learn
- Output:
  - Heart Disease Detected
  - No Heart Disease
